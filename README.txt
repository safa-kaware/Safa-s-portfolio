Safa Kaware — Portfolio Site
=============================

Files:
- index.html         The page structure/content
- styles.css         All styling
- script.js          Nav menu, scroll effects, contact form logic
- Safa_Kaware_Resume.pdf   Downloadable resume (linked from nav, hero, contact, footer)

Setup:
1. Add your photo file to this same folder.
2. Open index.html, find the <img src="20251124_133518 copy.jpg" ...> line
   in the hero section, and change the filename to match your photo.
3. Keep all files in this same folder when you upload to your host
   (Vercel, GitHub Pages, Netlify, etc.) — the links between them are
   relative paths, so they only work if the files stay together.

That's it — open index.html in a browser to preview locally.
