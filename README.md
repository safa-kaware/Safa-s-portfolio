# Safa Kaware — Portfolio

Personal portfolio site. Built with plain HTML, CSS, and JavaScript — no frameworks, no build step.

**Live site:** [safakaware.dev](https://safakaware.dev) *(update once deployed)*

## Structure

```
├── index.html               structure & content
├── styles.css                styling
├── script.js                  nav, scroll effects, contact form
└── Safa_Kaware_Resume.pdf     downloadable resume
```

## Features

- Fully responsive, mobile nav with slide-out menu
- Scroll-spy navigation
- Animated reveals on scroll
- Contact form (opens a pre-filled email — no backend needed)
- SEO-ready: meta tags, Open Graph, JSON-LD

## Run locally

Just open `index.html` in a browser. No install, no dependencies.
